# scheduler 一页速查（Linux 6.6）

> 用法：先扫这张表建立索引，再按需跳转对应章节。所有事实均与分册各章交叉核对（基准 v6.6）。

## 1. 数据结构五件套

| 结构 | 关键字段 | 详见 |
| :--- | :--- | :--- |
| `task_struct` | `sched_class`（行为入口）、`policy/prio`、`se/rt/dl`（三套实体）、`cpus_ptr`、`sched_migrated` | [02-核心数据结构](02-核心数据结构.md) |
| `sched_entity` | `load_weight`（权重=1024×nice0 比例）、`vruntime`、`slice`（=base_slice×权重换算）、`deadline`（EEVDF）、`load_avg/util_avg`（PELT）、`util_est` | [02](02-核心数据结构.md)/[05](05-PELT与利用率追踪.md) |
| `cfs_rq` | `nr_running`（本层）、`h_nr_running`（含子树）、`avg`（PELT 聚合）、`curr`/`leftmost`（rbtree 缓存） | [02](02-核心数据结构.md) |
| `rq` | `nr_running`、`cfs/rt/dl` 三队列、`cpu_capacity*`（含 thermal 扣减）、`clock_pelt`（虚拟时间源） | [02](02-核心数据结构.md) |
| `sched_class` | `enqueue/dequeue_task`、`pick_next_task`、`task_tick`、`switch_mm?`（6.6 无此回调——mm 切换在 context_switch） | [04-上下文切换](04-调度时机与上下文切换.md) |

## 2. 调度类优先级（链接段排序）

```
stop_sched_class > dl_sched_class > rt_sched_class > fair_sched_class > idle_sched_class
（__sched_class_highest[]…__sched_class_lowest[] 链接段数组；
  for_each_sched_class 自高向低遍历——pick_next 的选择序）
```

## 3. EEVDF 速记（[03-EEVDF](03-CFS与EEVDF详解.md)）

```
eligibility：vruntime − lag ≤ 0（lag<0 提前可跑，lag>0 欠债）
deadline    ：ve->deadline = vruntime + ceil(_slice/weight 比例)
pick        ：红黑树上找 eligible 且 deadline 最小的实体（pick_eevdf）
slice       ：se->slice = sysctl_sched_base_slice（默认 750000ns，
              ★仅 debugfs /sys/kernel/debug/sched/base_slice_ns——
              第 53 轮勘误已注非 sysctl，此处路径同步修正）
交互任务    ：低权重 → 长 deadline → 早被选中（无需启发式 boost）
```

## 4. PELT/util 速记（[05-PELT](05-PELT与利用率追踪.md)）

```
满额 util_avg = 1024（SCHED_CAPACITY_SCALE）；约 32ms 半衰（y^32=1/2）
util_est   ：EWMA 突发补偿（last×3/4 + last_util×1/4）
uclamp     ：四层来源（任务/组/系统/RT 默认）取交；桶聚合 5 桶
消费方     ：schedutil（effective_cpu_util 含 uclamp_rq_util_with）、
             EAS capacity 判定、负载均衡（avg）
```

## 5. RT / DL 关键参数（[06-RT与DL](07-实时与Deadline调度.md)）

| 参数 | 默认 | 含义 |
| :--- | :--- | :--- |
| `sched_rt_runtime_us` | 950000（950ms） | RT 组带宽配额 |
| `sched_rt_period_us` | 1000000（1s） | 配额周期——RT 最多吃 95% |
| `sched_dl_period_max/min_ns` | 4194304×… / 10000（DL 开机范围） | dl period 合法域 |
| dl 属性 | runtime/period/deadline | EDF+CBS：到期补时 CBS throttling |

## 6. 负载均衡 / EAS（[07-调度域](06-调度域与负载均衡.md)）

```
sched_domain 层级（x86 典型）：SMT → MC(L2 共享) → DIE → NUMA
newidle balance：唤醒路径的"顺手拉"（util 对比 + 迁移代价折算）
EAS：sched_energy_aware 开关；capacity 扣 thermal（power 分册联动）
CPU 迁移代价：sysctl_sched_migration_cost_ns（唤醒后粘滞窗）
```

## 7. sysctl 速查（/proc/sys/kernel/）

```
（★第 53 轮勘误：sched_base_slice_ns 与 sched_migration_cost_ns
  并非 sysctl——6.6 仅存在于 debugfs（sysctl 表 grep 零命中，
  对照 13 章）；下列为核实存在的 kernel.* 项）
sched_rt_runtime_us        RT 配额（950ms）——rt.c:42 注册
sched_rt_period_us         RT 周期（1s）——rt.c:35
sched_uclamp_util_min/max  系统级 clamp 天花板（默认 1024）
sched_uclamp_util_min_rt_default   RT 保底——core.c:4697
sched_energy_aware         EAS 开关（1）——topology.c:245
sched_autogroup_enabled    autogroup——autogroup.c:14
sched_schedstats           统计开关——core.c:4672
numa_balancing             0/1/tiering——core.c:4706
（base_slice/migration_cost_nr_migrate 族调参走
  /sys/kernel/debug/sched/——见 13 章全表）
```

## 8. 观测命令速查

```
cat /sys/kernel/debug/sched/debug   # 全 rq/rq_tree dump（CONFIG_SCHED_DEBUG；
                                     # ★勘误：/proc/sched_debug 已于 5.15 前后移除，
                                     # 由 debugfs 的 sched/debug 取代）
cat /proc/<pid>/sched            # 该任务的 vruntime/slice/nr_switches
cat /proc/<pid>/schedstat        # 三元组（顺序勘误·第 46 轮审计）：
                                  # sum_exec_runtime(运行)/run_delay(等待)/
                                  # pcount(上 CPU 次数)——fs/proc/base.c:482-485
perf sched record + perf sched latency   # 延迟分布
perf sched map                   # CPU↔任务时间线
cat /proc/pressure/cpu           # PSI 停顿率
cat /sys/fs/cgroup/.../cpu.stat  # throttled_nr_periods/throttled_usec
tracefs: sched:sched_wakeup*, sched:sched_switch
```
