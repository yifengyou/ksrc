## 2. 入口协议速记（[01](01-系统调用入口与分发.md)）

```
x86_64：syscall 指令 → entry_SYSCALL_64 → do_syscall_64
  （rax=号、rdi/rsi/rdx/r10/r8/r9=参数）；返回 user 模式 sysret
arm64：SVC #0 → el0_sync → invoke_syscall（x8=号、x0-x5=参数）
通用层（kernel/entry/common.c）：入口 work 钩子序列（信号/单步/
  audit——顺序见 04 章时间轴）；syscall 重启（restart_syscall）
```

## 3. 安全时间轴速记（[04](04-LSM与安全钩子顺序.md)）

```
ptrace（tracer 可改）→ seccomp（"after ptrace"原句）→ 调用号重读
  → trace_sys_enter → audit → 执行（LSM 钩子在实现内部对象访问点）
```

## 4. seccomp 速记（[02](02-seccomp.md)/[07](07-seccomp过滤器与BPF验证.md)）

```
模式：STRICT（白名单 4 调用）/ FILTER；SECCOMP_MODE_DEAD（:33）
动作八值：KILL_PROCESS=0x80000000 / KILL_THREAD=0x0 / TRAP=0x00030000
  / ERRNO=0x00050000 / USER_NOTIF=0x7fc00000 / TRACE=0x7ff00000
  / LOG=0x7ffc0000 / ALLOW=0x7fff0000
验证器：seccomp_check_filter 白名单（LD|W|ABS→LDX 改写）+
  bpf_check_classic + cBPF→eBPF 迁移；BPF_MAXINSNS=4096
filter：prev 链只增不删；action_cache 双位图快路；
  TSYNC 传播 no_new_privs；notif id = per-filter 递增计数器
  （next_id++——第 3 轮复查勘误后的正确口径）
```

## 5. io_uring 速记（[03](03-io_uring.md)/[05](05-iowq与取消状态机.md)）

```
三环：SQ/CQ ring（共享内存）+ SQE 数组；syscalls：
  io_uring_setup(425) / io_uring_enter(426) / io_uring_register(427)
  （★syscall_64.tbl 本轮补核）
零系统调用形态：SQPOLL（内核轮询线程吃 SQ）/ IOPOLL（收割免 enter）
io-wq：per-task 私有池、64 桶 inode hash、BOUND/UNBOUND 双账本；
  worker 线程名 iou-wrk-%d；取消（io_sync_cancel 按号精准 /
  io_uring_cancel_generic 的 inflight 轮询收尾）
```

## 6. vDSO 速记（[06](06-vDSO与clock_gettime.md)）

```
定位：AT_SYSINFO_EHDR 引导库；x86 无手写汇编（直接 include 泛型 C）
数据页：vdso_data{seq, clock_mode, cycle_last, mask, mult, shift,
  basetime[]}；timens 页"卡 seq"重定向（VDSO_CLOCKMODE_TIMENS）
更新侧：clocksource.vdso_clock_mode 字段驱动（换钟源自动回落
  fallback 系统调用）
```

## 7. 观测速查

```
strace -f -e trace=io_uring_enter,seccomp    # 按号过滤
perf trace / perf record -e raw_syscalls:*
cat /proc/<pid>/syscall                      # 阻塞中的调用号+参数
bpftrace 'tracepoint:syscalls:sys_enter_*'   # 高频榜
io_uring 深查：/proc/<pid>/task/*/comm | grep iou（池规模）
seccomp 状态：grep Seccomp /proc/<pid>/status（0/1/2 + filters 层数）
vDSO 生效验证：strace -c 无 clock_gettime 残留（clock_mode 正常时）
```
