## 2. genirq 处理主线（[03-中断处理流程](03-中断处理流程.md)）

```
硬件入口（idt/vector）→ common_interrupt → irq_enter_rcu
  → desc->handle_irq（flow handler，chip 语义适配）
  → handle_irq_event → action->handler 链（共享中断逐个试）
  → 硬处理尾：若 action 带 thread_fn → 唤醒内核线程，返回 IRQ_WAKE_THREAD
  → irq_exit_rcu →（含 softirq 检查，见 §5）
NMI 走独立入口（不持 desc->lock、不可睡）
```

## 3. flow handler 三型（[03](03-中断处理流程.md)）

| 型 | 代表 | 语义 |
| :--- | :--- | :--- |
| level | `handle_level_irq` | 收到即 mask+ack，handler 期间防重入，尾 unmask |
| edge | `handle_edge_irq` | ack 但不 mask（边沿丢失防御：挂起再触发） |
| fasteoi | `handle_fasteoi_irq` | 硬件自动 EOI，软件只跑 handler（x86 APIC/LAPIC 主流） |

## 4. irq_domain 速记（[04-irq_domain](04-irq_domain与中断号映射.md)）

```
三条 revmap：linear（revmap[] 柔性数组，≤256 常用）/ tree（radix+RCU，
  稀疏大 hwirq/MSI）/ nomap（软件号直用，少见）
查找：fwspec → domain 匹配（fwnode/DOMAIN_BUS_*）→ translate →
  __irq_domain_alloc_irqs（层级：父 domain 递归 alloc）
★ops 实现 alloc 即自动置 IRQ_DOMAIN_FLAG_HIERARCHY
  （irq_domain_check_hierarchy）
```

## 5. softirq 速记（[05-softirq与tasklet](05-softirq与tasklet.md)）

```
十类（枚举序，interrupt.h:550-561 核对）：
  HI=0 → TIMER → NET_TX → NET_RX → BLOCK → IRQ_POLL → TASKLET →
  SCHED → HRTIMER → RCU（恒居末——注释"Preferable RCU should
  always be the last softirq"）
执行预算：单次 __do_softirq 至多 10 次重启（MAX_SOFTIRQ_RESTART=10）
  或 2ms（MAX_SOFTIRQ_TIME=msecs_to_jiffies(2)）——超限叫醒
  ksoftirqd/%u 承接（此后软中断回归正常调度权重）
raise：local_bh_disable 上下文内 mark_bh? （6.6 现名 raise_softirq）
  pending 位图 per-CPU；lockdep 断言 in_softirq 不可再 bh_disable
```

## 6. 线程化中断 / tasklet（[06-线程化中断](06-线程化中断.md)）

```
request_threaded_irq(irq, primary, thread_fn, flags, ...):
  IRQF_ONESHOT：primary 跑完保持 masked，thread 完成才 unmask——
    level 中断防再次触发的标准姿势
  IRQF_SHARED：dev_id 做共享键；handler 返回 IRQ_NONE 放行下一个
threaded 与 PREEMPT_RT：RT 下几乎所有 handler 强制线程化
tasklet：仍由 TASKLET_SOFTIRQ/HI_SOFTIRQ 驱动（软中断上下文、
  原子性）——新代码建议改 threaded IRQ 或 workqueue（后续内核
  已计划移除 tasklet）
```

## 7. 观测命令速查

```
cat /proc/interrupts            # 每 CPU 向量计数表（共享中断聚合）
cat /proc/softirqs              # 十类 per-CPU 计数（对照 §5 枚举序）
cat /proc/irq/<n>/smp_affinity  # IRQ 亲和（hex 掩码；写入迁移）
watch -n1 'grep NET_RX /proc/softirqs'   # 收包风暴判定
perf probe + tracepoints: irq:irq_handler_entry/exit、softirq:*
irqbalance 服务的影响基线（周期性迁移 vs 手动钉核）
```

## 8. 调试要点

```
中断风暴：/proc/interrupts 单行秒级狂增 → 确认是否共享误注册
  （IRQ_NONE 连锁）/ 设备故障重触发
丢失中断（edge）：计数对不上设备侧 → flow handler 的挂起语义与
  mask 时窗（[03 章]）
softirq 饥饿：ksoftirqd 长期 100% → 谁在疯狂 raise（perf softirq
  tracepoint 分型）
NMI watchdog 与 perf NMI 的共存（[03 章] NMI 节）
```
