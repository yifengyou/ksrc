## 2. cgroup v2 核心机制（[01](docs/01-v2层级与线程模式.md)）

```
挂载：cgroup2 单挂载点；无层次命名——纯目录树
启用：cgroup.controllers（可用的）/ cgroup.subtree_control（启给子代，
  "+cpu +memory" 增量式）；进程放 cgroup.procs（线程放 cgroup.threads）
委托：子目录 + 子树控制权下发（systemd 的 slice/scoped/scope 树）
threaded 模式：cgroup.type = threaded/domain（线程级资源域）
```

## 3. cpu 控制器速记（[02](docs/02-cpu控制器.md)）

```
cpu.max = "<quota> <period>"（"max 100000"=不限流；默认 quota=周期满额）
  实现：CFS 带宽（cfs_b->quota/period，周期 100ms 典型；burst 补丁帧）
cpu.weight = 1..10000（默认 100；CGROUP_WEIGHT_* 于 include/linux/
  cgroup.h:39-41 本轮补核）——与 CFS nice 权重换算：
  weight×100/1024（core.c:11327 原式）
cpu.stat（v2 六字段）：usage_usec / user_usec / system_usec /
  nr_periods / nr_throttled / throttled_usec（core.c:11283-11290
  本轮补核）
cpu.uclamp.min / cpu.uclamp.max（%值，root 不可设）
cpu.pressure（PSI）
```

## 4. memory 控制器速记（[03](docs/03-memory控制器.md)/[05](docs/05-memcg回收深挖.md)）

```
memory.current（当前用量）/ memory.max（硬限→OOM）/
  memory.high（软限→罚睡节流）/ memory.min（保护）/ memory.low（低保护）
memory.stat：anon/file/kernel 三大桶 + events/swap 事件 + pgscan/
  pgsteal（回收吞吐——05 章观测链）
memory.swap.max / swap.current；memory.reclaim（写值强制回收）
回收语义：high 罚睡（schedule_timeout_killable(penalty)）vs
  max 的 MAX_RECLAIM_RETRIES→OOM——双失败语义（05 章核对）
```

## 5. io 控制器与 cpuset 速记（[04](docs/04-io控制器与cpuset.md)）

```
io.max：绝对上限（rbps/wbps/iops 双向）
io.cost：成本模型（vrate 反馈环——6.6 无 AUTOMATE，后续版本特性）
io.latency：目标延迟驱动（scale_lat 迟滞）
io.stat / io.pressure / io.qos（成本模型参数）
cpuset.cpus / cpuset.mems / cpuset.cpus.partition（root 与
  isolated 两态——"有效 isolated"的 6.6 语义见 04 章）
```

## 6. uclamp 与 css_set 速记（[06](docs/06-uclamp深挖.md)/[07](docs/07-css_set深挖.md)）

```
uclamp effective = 系统天花板 ∩ 组区间(任务请求)：
  clamp(req.value, tg_min, tg_max) 再过 sysctl 上限（06 章）
css_set：任务组合去重枢纽——同组合任务共享实例；subsys[] +
  prev 链只增不删（fork 继承链变长=容器防绕过地基）
```

## 7. PSI 与观测

```
{cpu,memory,io}.pressure 格式：
  "some avg10=X avg60=X avg300=X total=Y"
  some=至少一个任务停顿；full=全部任务停顿（memcg high 节流的
  特征信号）
memory.events（oom/oom_kill 高水位计数）
快速体检：systemd-cgtop / cat /sys/fs/cgroup/.../cpu.stat
```

## 8. 版本边界提醒

```
6.6 无：io.cost AUTOMATE（后续版本）、cgroup v1 的 nog 机制
  （03 章勘误）、threaded 域的 per-cgroup 单独 cpu 带宽（层级
  限制共享语义）
```
