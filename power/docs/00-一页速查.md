## 2. cpufreq 速记（[02](02-cpufreq.md)）

```
对象：policy（每频域一个：related_cpus + 约束 + governor）
governor：schedutil（默认，吃 util）/ performance / powersave /
  userspace（ondemand 为 legacy）
约束层：freq_qos（min/max 请求链；thermal/cpufreq_cooling 用它
  clamp 上限——thermal 章联动）
sysfs：/sys/devices/system/cpu/cpuN/cpufreq/{scaling_*,cpuinfo_*}
```

## 3. cpuidle 速记（[03](03-cpuidle.md)）

```
state 梯度：/sys/devices/system/cpu/cpuN/cpuidle/state*/
  {name, desc, latency, residency, power, usage, time, disable,
   above, below}（★第 6 轮复查勘误：文件名是 latency/residency
   而非 exit_latency_us/residency_us——sysfs.c:330-343 全表）
governor：menu（预测驻留）/ ladder（固定步降）
NOHZ 联动：深 idle 需 tick 停摆（timers 章的 NOHZ_IDLE）；
  polling state（state0）永不深睡
```

## 4. runtime PM 速记（[04](04-runtime-PM.md)）

```
引用计数：pm_runtime_get_sync/put_sync（device->power.usage_count）
autosuspend：usage=0 后再等 autosuspend_delay_ms 才真 suspend
  （批量抖动抑制）
状态机：rpm_suspend/resume 挂 work（pm_wq）；IRQSAFE 变体
sysfs：/sys/devices/.../power/{control,runtime_status,
  autosuspend_delay_ms}
```

## 5. suspend 速记（[05](05-suspend与s2idle.md)）

```
/sys/power/state：freeze（s2idle）/ mem（默认 s2idle 或 deep，
  由 /sys/power/mem_sleep 选）/ disk（hibernate）/ standby
  ★本轮补核：mem_sleep_labels[] = {"s2idle","shallow","deep"}
  （kernel/power/suspend.c:42-46）
三级时序：prepare→suspend（noirq）→late；唤醒逆序
wakeup source：device_init_wakeup 注册；事件记账
  ★本轮补核：/sys/kernel/debug/wakeup_sources 存在
  （drivers/base/power/wakeup.c:1178，postcore_initcall）
```

## 6. thermal 速记（[06](06-thermal框架.md)）

```
/sys/class/thermal/thermal_zone*/{temp,type,policy,mode}
/sys/class/thermal/cooling_device*/{cur_state,max_state}
trip 四类型（ACTIVE/PASSIVE/HOT/CRITICAL）；governor：
  step_wise（默认）/ power_allocator(IPA) / user_space
调度联动：arch_scale_thermal_pressure 扣 capacity（EAS 实时感知）
```

## 7. devfreq 速记（[07](07-devfreq与pm_qos.md)）

```
/sys/class/devfreq/<dev>/{governor,cur_freq,min/max_freq,
  polling_interval,trans_stat}
governor：simple_ondemand（90/5）/performance/powersave/
  userspace/passive（可跟随 cpufreq）
```

## 8. EPP 速记（[08](08-HWP与EPP调优.md)）

```
/sys/.../cpufreq/energy_performance_preference
五档：performance(0x00)/balance_performance(0x80)/
  balance_powersave(0xC0)/power(0xFF)/default
/sys/devices/system/cpu/intel_pstate/{status,hwp_dynamic_boost}
实测法：turbostat 扫五档画 Bzy_MHz-PkgWatt 曲线
```

## 9. idle 注入速记（[09](09-idle注入与powerclamp.md)）

```
idle_inject 框架（drivers/powercap/idle_inject.c）：
  play_idle_precise(duration, latency) + hrtimer 周期
powerclamp 模块参数：duration=6jiffies/max_idle=50%（默认）/
  window_size=2/cpumask（0644 带护栏）
观测：/sys/module/intel_powerclamp/parameters/*
```

## 10. 观测命令总表

```
turbostat            # 频率/功耗/C-state 一屏（EPP/thermal 调优基线）
powertop             # wakeup 清单与 runtime PM 建议
cat /sys/power/pm_debug_messages? （0/1 排障开关）
sleepgraph / turbostat --interval 1 组合做 suspend 时延剖面
perf stat -e power:cpu_idle （tracepoint 佐证 idle 深度分布）
```
