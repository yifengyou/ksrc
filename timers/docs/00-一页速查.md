## 2. 三层定时 API 梯度

```
jiffies 级（ms~s 精度，海量）：mod_timer——非级联轮（§3）
ns 级（高精度）：hrtimer_start（§4）
进程可见 POSIX：timer_create/settime（CLOCK_MONOTONIC 等 clockid →
  映射到 hrtimer 硬/CPU 端软）——[07-posix](07-posix定时器.md)
```

## 3. 非级联时间轮速记（[04](04-时间轮与低分辨率定时器.md)）

```
9 级 × 每级 64 槽（LVL_DEPTH=9、LVL_BITS=6——timer.c 已核对）
  0 级粒度=1 tick；级 k 粒度 LVL_GRAN(k)=tick<<(k×LVL_CLK_SHIFT)
  到期批量消费（同 tick 内的轮内过期 + 上级下放——全部 O(1) 均摊）
timer slack：默认 50µs（init_task.c:133 ".timer_slack_ns = 50000,
  50 usec default slack"）——批量到期窗口；prctl(PR_SET_TIMERSLACK)
  可调、fork 继承（fork.c:2413）
```

## 4. hrtimer 速记（[05](05-hrtimer高精度定时器.md)）

```
per-CPU 8 基（include/linux/hrtimer.h 已核对）：MONOTONIC/REALTIME/
  BOOTTIME/TAI × hard/soft 各 4（soft 供 PREEMPT_RT 迁移）
  base = softtimer ? HRTIMER_MAX_CLOCK_BASES/2 : 0
每基一棵 timerqueue（红黑树）：取最左 expires 编程 clockevent
模式：HRTIMER_MODE_ABS/REL（+/K/PINNED 组合）
resolution：高精度开（hrtimer_interrupt）vs 退化为 tick
```

## 5. tick / NOHZ 速记（[06](06-tick与NOHZ.md)）

```
periodic tick：HZ（250 典型服务器/1000 桌面）——timekeeping 补间
  + scheduler tick + watchdog 触发
NOHZ_IDLE（CONFIG_NO_HZ_IDLE）：空闲停 tick（按下一 timer 需求
  编程）——省功耗/减 jitter
NOHZ_FULL（nohz_full=cpulist）：运行态也停 tick（仅 1 个响应
  housekeeping CPU）——计算密集/低噪声场景；代价：时间戳退化
  （cputime 的 tick 估算）与调度公平（cgroup ch02）
residency 观测：/proc/timer_list 的 NOHZ 字段
```

## 6. timekeeping / NTP 速记（[03](03-timekeeping与clock_gettime.md)）

```
tk_core（写）+ shadow（seq 读）——vdso 章的 seq 协议同一套
时间推进：cycle 差 × mult >> shift + xtime_nsec（PELT 同款数学）
NTP：adjtimex(2)（NTP daemon）→ time_state（TIME_OK/INS/DEL
  闰秒状态机）→ freq/mult 微调；clocksource watchdog 剔除漂移源
```

## 7. 观测命令速查

```
cat /proc/timer_list       # hrtimer/事件设备全 dump（kernel/time/
                            timer_list.c——6.6 仍在；/proc/timer_stats
                            已删除——老命令注意）
perf record -e timer:hrtimer_start -e timer:hrtimer_expire_entry
tracefs timer:* 族         # 定时器热点分布
cat /sys/devices/system/cpu/cpuidle/*/residency_us   # NOHZ idle 佐证
perf stat -e task-clock 观测 tick 噪声（NOHZ_FULL 前后对照）
hrtimer 风暴排查：/proc/timer_list 单 CPU base 深度异常 →
  找到高频 start 的调用方（tracepoint 直指）
```
