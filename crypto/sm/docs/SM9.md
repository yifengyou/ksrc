# SM9

SM9 是中国国家密码管理局于 **2016年3月28日** 正式发布的**标识密码算法标准**（标准号：**GM/T 0044-2016**），属于**非对称密码体系**，是我国自主研发并具有完全自主知识产权的密码算法。它也是我国首个**全体系纳入 ISO/IEC 国际标准**的非对称密码算法。

---

### 一、核心特点：基于身份的密码（IBC）

SM9 最大的创新在于采用 **“标识即公钥”** 的理念：

- **无需数字证书**：传统公钥密码（如 RSA、SM2）需要通过 PKI 体系分发和验证公钥证书，而 SM9 直接使用用户的**身份标识**（如邮箱、手机号、身份证号、设备 ID 等）作为其公钥。
- **简化密钥管理**：极大降低了密钥分发、存储和验证的复杂性，特别适合物联网、移动通信、云服务等大规模分布式场景。

> 例如：若要给 `user@example.com` 发送加密消息，只需知道其邮箱地址，系统即可自动计算出对应的公钥进行加密。

---

### 二、数学基础：双线性对（Bilinear Pairing）

SM9 的安全性建立在**椭圆曲线上的双线性映射**（Pairing）之上，具体包括：

- 使用两条椭圆曲线 $G_1$ 和 $G_2$（定义在有限域上）
- 一个目标群 $G_T$
- 双线性映射 $e: G_1 \times G_2 \rightarrow G_T$，满足：
    - **双线性**：$e(aP, bQ) = e(P, Q)^{ab}$
    - **非退化性**：映射结果不恒为单位元
    - **可计算性**：可在多项式时间内计算

该结构使得 SM9 能在保持高安全性的同时实现高效的密钥派生与加解密。

---

### 三、安全强度

- **等效安全强度**：约等于 **3072 位 RSA**（据新华网报道）
- **抗攻击能力**：依赖于**椭圆曲线离散对数问题**（ECDLP）和**扩域上的离散对数问题**（DLP）的计算困难性
- **标准化认可**：已纳入 **ISO/IEC 18033-5** 等国际标准

---

### 四、主要功能模块（7种密码操作）

SM9 标准定义了完整的密码协议体系，包括：

| 功能 | 说明 |
|------|------|
| **主密钥生成** | 由可信的**私钥生成中心**（PKG）生成系统主密钥（签名主密钥 + 加密主密钥） |
| **用户私钥提取** | PKG 根据用户标识（如 email）为其生成唯一私钥 |
| **数字签名与验证** | 基于标识的签名方案（IBS） |
| **数据加密与解密** | 基于标识的加密方案（IBE） |
| **密钥协商** | 两方或多方基于身份协商出会话密钥 |
| **密钥封装/解封装** | 用于混合加密系统中的密钥传输 |

---

### 五、密钥体系结构

SM9 定义了 **5 类密钥**：

1. **签名主密钥**（MSK-S）：PKG 用于生成用户签名私钥
2. **加密主密钥**（MSK-E）：PKG 用于生成用户加密私钥
3. **用户签名私钥**：由 PKG 为用户签发，用于签名
4. **用户加密私钥**：由 PKG 为用户签发，用于解密
5. **主公钥**（MPK）：公开参数，用于加密和验证

> 注意：用户**不需要保管公钥**，因为公钥就是其身份标识；但必须安全保管由 PKG 分发的私钥。

---

### 六、典型应用场景

- **政务与金融系统**：身份认证、电子签章
- **物联网**（IoT）：设备间安全通信（设备 ID 即公钥）
- **移动支付**：基于手机号的加密交易
- **电子邮件安全**：直接用邮箱地址加密邮件
- **云存储加密**：用户标识绑定密钥，简化密钥轮换

---

### 七、与 SM2 的对比

| 特性 | SM9 | SM2 |
|------|-----|-----|
| 类型 | 标识密码（IBC） | 传统公钥密码（PKI） |
| 公钥形式 | 用户标识（如 email） | 随机生成的椭圆曲线点 |
| 是否需要证书 | ❌ 不需要 | ✅ 需要 |
| 密钥管理复杂度 | 低（集中式 PKG） | 高（需 CA 体系） |
| 适用场景 | 大规模、动态用户系统 | 传统企业/政府 PKI 环境 |

---

### 八、注意事项

- **信任模型依赖 PKG**：私钥生成中心（PKG）掌握主密钥，理论上可获取任何用户私钥，因此 PKG 必须高度可信且物理隔离。
- **不适合完全去中心化场景**：如区块链等无中心权威的环境，需结合其他机制（如分布式 PKG）使用。
