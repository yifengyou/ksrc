

# 高版本内核隐藏kallsyms_lookup_name

从 Linux 5.7 版本开始，内核决定不再导出 kallsyms_lookup_name 函数4610。这意味着，从5.7版本开始，内核模块无法再直接调用这个函数了。这样做的主要原因有：

减少滥用和非预期使用：内核开发者发现，kallsyms_lookup_name 主要被一些树外模块（out-of-tree modules） 滥用，特别是那些并非真正遵循GPL许可的模块，来访问其他非导出的内部符号10。这破坏了内核设计的模块化边界和封装性。

遵循最小权限原则：内核符号的导出应该严格控制。只有那些真正打算为模块提供接口的符号才应该被导出。kallsyms_lookup_name 本身原本主要是供内核内部使用的，并非作为一个通用的模块开发接口6。

安全性和稳定性考虑：允许模块随意查询和调用任何内核内部函数会增加系统的不稳定性和潜在的安全风险。模块可能因此调用到不稳定或内部接口，破坏内核的完整性。

简单来说，内核开发者认为这个函数被“用错了地方”，为了维护内核的长期健康和安全，决定将其“隐藏”起来。
