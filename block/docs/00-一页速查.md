# block 一页速查（Linux 6.6）

> 用法：与 scheduler/interrupt/timers/mm 速查同构。事实与分册各章交叉核对（基准 v6.6）。

---

## 1. 数据结构四件套

| 结构 | 关键成员 | 详见 |
| :--- | :--- | :--- |
| `request_queue` | `queue_hw_ctx`（hctx 数组）、`nr_hw_queues`、`tag_set`、`nr_requests`（默认 **BLKDEV_DEFAULT_RQ=128**）、`limits` | [03-blk-mq](03-blk-mq多队列.md) |
| `bio` | `bi_iter`（bvec 迭代器）、`bi_io_vec[]`（**≤256 段**，bio.h:13）、`bi_end_io` 回调 | [02-bio](02-bio与bio_vec.md) |
| `request`（mq 内部） | `rq_entry`（hctx 链表）、`tag`（sbitmap）、`rq_disk`/`bio` 载体、`deadline`（调度用） | [03](03-blk-mq多队列.md) |
| `blk_mq_hw_ctx` | `dispatch` 队列、`tags`（sbitmap 预留位图）、`cpumask`（CPU→hctx 映射） | [03](03-blk-mq多队列.md) |

## 2. bio 速记（[02](02-bio与bio_vec.md)）

```
bio_for_each_bvec/bio_for_each_segment 迭代三剑客；split 深挖见 02 章；
bio_alloc 优先 mempool（BIO_POOL）；clone：bio_clone_fast 只克隆描述
body 不克隆 bvec（共享需持引用计数）
```

## 3. 提交路径速记（[03](03-blk-mq多队列.md)）

```
submit_bio_noacct → blk_mq_submit_bio：
  ① 尝试合并（plug 里的尾 request——back merge 优先）
  ② 挂 per-task plug（批量积累，见 §4）
  ③ blk_mq_map_queue 选 hctx（CPU→hctx 映射）
  ④ blk_mq_get_tag（sbitmap）→ __blk_mq_issue_directly 或
     blk_mq_sched_insert_request（有 IO 调度器时）
```

## 4. plug 速记（[04](04-plug与批量合并.md)）

```
per-task plug（current->plug）：mq_list + cb_list（回调）
  blk_start_plug/blk_finish_plug；唤醒/调度点强制 flush
  issue：blk_mq_plug_issue_direct（直接下发同 hctx 批）
```

## 5. IO 调度器速记（[05](05-IO调度器.md)）

```
6.6 内置：none / mq-deadline（默认）/ kyber / bfq
/sys/block/<dev>/queue/scheduler 可运行时切换（每队列独立）
rq_qos 层：wbt（writeback throttle）+ iocost（cgroup v2 io.cost）
```

## 6. 完成路径速记（[06](06-完成路径与iostat.md)）

```
驱动 IRQ → blk_mq_complete_request → 远端 CPU 偏好完成（IPI/
softirq blk_mq_raise_softirq）→ blk_mq_end_request：
  account（part_stat）→ bio_endio 链 → plug 的 cb（batch completion）
iostat 数据源：/proc/diskstats 与 /sys/block/*/stat 同源
```

## 7. 观测命令速查

```
iostat -x 1                     # util% await r/s w/s
cat /sys/block/<dev>/queue/{scheduler,nr_requests,max_sectors_kb,rotational,nomerges}
blktrace -d <dev> -o - | blkparse -i -   # 全事件流（Q/C/D/..事件码）
echo 0 > nomerges / 2           # 合并开关实验（0=off 2=full）
```

## 8. 数值速记（本轮补核）

| 量 | 值 | 出处 |
| :--- | :--- | :--- |
| bio 最大段数 | BIO_MAX_VECS = **256** | include/linux/bio.h:13 |
| nr_requests 默认 | BLKDEV_DEFAULT_RQ = **128** | include/linux/blk-mq.h:16 |
| max_sectors 默认 | BLK_DEF_MAX_SECTORS = **2560**（≈1.25MB） | include/linux/blkdev.h:1083 |
| 安全扇区（旧接口） | BLK_SAFE_MAX_SECTORS = 255 | 同上 |
| 段大小上限 | BLK_MAX_SEGMENT_SIZE = 65536 | 同上 |
