# mm 一页速查（Linux 6.6）

> 用法：与 [scheduler](../../scheduler/docs/00-一页速查.md)/[interrupt](../../interrupt/docs/00-一页速查.md)/[timers](../../timers/docs/00-一页速查.md) 同构。事实与分册各章交叉核对（基准 v6.6）。

---

## 1. 三层物理模型

| 结构 | 关键成员 | 详见 |
| :--- | :--- | :--- |
| `page`（每 4K 一枚） | `flags`、`_refcount`、`_mapcount`、`mapping|slab 化身`、`index`、`lru`、`memcg_data` | [page](../page/page.md) |
| `zone` | `free_area[MAX_ORDER+1]`（order 空闲链+MIGRATE 分表）、`watermark[3]`（MIN/LOW/HIGH）、`managed_pages`、`per_cpu_pageset` | [zone](../zone/zone.md)/[buddy](../buddy/buddy.md) |
| `pglist_data`(node) | `node_zones[]`、`node_zonelists`（分配回落序）、`node_mem_map` | [node](../node/node.md) |
| `memblock`（启动期） | memory/reserved 双 region 数组——memblock→buddy 交接 | [memblock](../memblock/memblock.md) |

## 2. 页分配速记（[buddy](../buddy/buddy.md)）

```
alloc_pages(gfp, order)：
  fast path：pcp（仅 order 0）→ __rmqueue_smallest 摘链（order→order+1 劈半）
  slow path：水位检查（__zone_watermark_ok）→ wakeup kswapd /
    __alloc_pages_slowpath（compaction/reclaim/OMP）
  MIGRATE_* 回落：UNMOVABLE→MOVABLE→RECLAIMABLE…（防碎片分族）
反方向：put_page → __free_pages → 合并伙伴（直到 MAX_ORDER=10）
```

## 3. 小对象速记（[slub](../slub/slub.md)/[kmalloc](../kmalloc/kmalloc.md)）

```
SLUB：per-cpu freelist（c->freelist）+ per-cpu partial + node partial
  三级缓存；cmpxchg 双播（tid 低 12 bit cpu+tid）
kmalloc-<size> 常备 cache 族（8B..8K+；cg/dma 变体）
专用：kmem_cache_create（名字/size/align/flags）
```

## 4. 虚拟内存速记（[vma](../vma/vma与mmap生命周期.md)）

```
task→mm→mm_mt（maple tree，6.6 主索引——vm_prev/next 已删）
  vma_iter_config→prealloc→store 两阶段提交；vma_merge 合并规则
  文件侧挂 i_mmap interval tree；匿名侧 anon_vma 链
PER_VMA_LOCK（6.4+）：缺页快速路径绕过 mmap_lock
fork：dup_mmap 逐 vma 复制（vm_flags 定共享面）
```

## 5. 文件页速记（[pagecache](../pagecache/pagecache与writeback.md)）

```
address_space（per-inode）：i_pages xarray + 三枚标签
  （DIRTY/TOWRITE/WRITEBACK——回写账本）
脏页节流：pos_ratio 比例控制（freerun=(thresh+bg)/2、
  setpoint=(freerun+limit)/2）；balance_dirty_pages 罚睡
回写：write_cache_pages 主循环 + tag_pages_for_writeback 防活锁
  （DIRTY→TOWRITE 两段）
```

## 6. KSM / zswap 速记（[ksm](../ksm/ksm与zswap.md)）

```
KSM：MADV_MERGEABLE 显式开启；unstable/stable 双树（checksum 指纹）
  ——仅 6.6 无 smart scan（6.7 起才有，如实记录）
zswap：每 swap 设备一棵 rbtree；same-filled 直存（value 复用 handle）；
  32 路 zpool 分流（ZSWAP_NR_ZPOOLS=32）；max_pool_percent=20 限额回写
```

## 7. 缺页路径速记（[pagefault](../pagefualt/pagefault.md)/[cow](../cow/cow.md)）

```
do_user_addr_fault → handle_mm_fault：
  匿名 → do_anonymous_page（零页/分配）
  文件 → filemap_fault（page cache 优先，预读窗口）
  swap → do_swap_page（zswap 命中优先）
写时复制：wp_page_copy（fork 后首写）
NUMA balancing：mmu notifier 采点 → 迁移建议
```

## 8. 观测与 sysctl 速查

```
cat /proc/meminfo            # MemAvailable 比 free 更准
cat /proc/buddyinfo          # 每 zone 每 order 空闲数（碎片体检；
                              # 本轮核对：vmstat.c:2138 存在，0444）
cat /proc/pagetypeinfo       # MIGRATE 分族明细（0400，:2139）
cat /proc/zoneinfo           # 水位/spanned/present/managed
cat /proc/slabinfo           # SLUB 各 cache 统计
cat /proc/pagetypeinfo + /sys/kernel/debug/extfrag/unusable_index
sysctl vm.min_free_kbytes    # 水位地基（初始 1024KB，运行期自调——
                              # page_alloc.c:287 本轮核对）
sysctl vm.swappiness / vm.dirty_* / vm.overcommit_memory
echo 3 > /proc/sys/vm/drop_caches   # 排障专用（pagecache+slab 可回收）
```
